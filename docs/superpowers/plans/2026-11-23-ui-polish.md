# CCTV Monitor UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Perbaiki tombol CLOUD yang teksnya tak terlihat dan rapikan UI beranda serta sheet kontrol tanpa mengubah logika streaming/kontrol.

**Architecture:** Perubahan murni resource Android (XML layout + dimens). Tidak ada perubahan logika Kotlin. Semua id view yang dipakai `MainActivity`, `SettingsActivity`, dan `CameraControlSheet` harus tetap sama; hanya atribut tampilan dan TextView tanpa id yang ditambahkan.

**Tech Stack:** Android XML layout, Material3 `MaterialButton`, vector drawables, Gradle Kotlin DSL.

**Spec:** `docs/plans/2026-11-23-ui-polish-design.md`

## Global Constraints

- `CAMERAS_PER_PAGE = 4`, `GRID_COLUMNS = 2` — jangan diubah.
- `minSdk = 24`, `targetSdk = 34`, Material3 Dark theme.
- Jangan menyentuh `ControlRepository`, `PlayerManager`, `CloudIsapiClient`, atau workaround InputProxy.
- Jangan mengubah id view yang direferensikan Kotlin.
- Warna tombol filled accent/danger/warning/info → teks & ikon `@color/black`.
- Tombol outlined → teks & ikon warna status; text button → `@color/accent`.
- `btnAway.backgroundTintList` diubah runtime (`MainActivity:666`) → tetap filled, jangan dijadikan outlined.

## Review Focus

- Tombol CLOUD saat terikat: label `CLOUD: <device> — ubah` harus terbaca → cek blok `btnBindCloud` memakai `textColor="@color/black"` dan bukan `@color/accent`.
- `btnAway` tetap filled agar `backgroundTintList` runtime berfungsi → cek style tidak diubah.
- Semua id view dipertahankan → cek `findViewById` di Kotlin masih kompil (build sukses).
- Teks status chip di grid tidak terpotong → cek `tvStatus` masih `maxLines` default dan container tidak dibatasi tinggi tetap.
- Tidak ada regresi native SDK → cek logcat tidak ada `UnsatisfiedLinkError` / `FATAL` setelah build terpasang.
